# Robot Échecs — téléchargements

Ce dépôt ne contient **que les versions publiées** de l'application Android
Robot Échecs. Le code source vit dans un dépôt privé.

## Installer

Va dans [Releases](../../releases), télécharge le fichier `.apk` de la dernière
version et ouvre-le sur ton téléphone. Android demandera l'autorisation
d'installer une application depuis cette source, c'est normal hors boutique.

Une fois l'application installée, elle vérifie elle-même les nouvelles versions
et propose la mise à jour.

## latest.json

Le fichier `latest.json` à la racine est le manifeste lu par l'application :
numéro de version, lien de téléchargement, empreinte SHA-256 et notes de version.
Il est mis à jour automatiquement à chaque publication.
